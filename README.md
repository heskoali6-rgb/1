# Fixab IPTV

واجهة ويب/PWA خفيفة لمشاهدة قوائم M3U التي تملك حق استخدامها.

## التشغيل محليًا

```powershell
node --run serve
```

ثم افتح `http://localhost:4173`.

- أضف رابط M3U متاحًا من مزوّدك أو اختر ملف M3U من جهازك.
- لا تتضمن هذه النسخة قنوات أو بيانات اشتراك.
- يتطلب البث أن يسمح مزوّد القائمة بالوصول من المتصفح.
